## 三毛机场 2.0 的流量倍率要注意

选机场订阅时，除了价格，流量倍率也很重要。

根据第三方资料转述的倍率规则，相关节点曾出现以下设置：

| 节点或时段 | 参考倍率 |
| --- | ---: |
| 03:00—08:59 | 1倍 |
| 09:00—19:59 | 2倍 |
| 20:00—次日01:59 | 3倍 |
| 02:00—02:59 | 2倍 |
| 部分台湾节点 | 5倍 |

这张表属于第三方资料中的历史规则，未经过我在当前官网后台的独立核验，不应直接当作今天仍然生效的承诺。下单前请查看当时的套餐说明和节点公告。

倍率的意思是：如果某个节点按3倍扣流量，实际传输1GB数据，可能消耗3GB套餐额度。

因此，标称120GB的套餐，在3倍倍率下，单纯按流量扣除计算，相当于最多传输约40GB数据。实际消耗还取决于使用的节点和不同时段的规则。

**简单说，便宜不代表一定划算，先看倍率再算实际流量，才更有参考价值。**

- 当前套餐价格是否与第三方整理一致。
